# Web Console 使用说明

这份文档是写给“已经装好 Polaris，准备开始用”的人看的。

如果你只是想知道：

- 页面从哪里打开
- 每一页是干什么的
- 先点哪里最合适

那从这里开始就对了。

## 先打开 Console

启动 Polaris：

```bash
polaris start
```

查看 Console 地址：

```bash
polaris console-url
```

或者直接运行：

```bash
polaris status
```

然后在浏览器里打开输出的地址。

默认一般会是：

- `http://127.0.0.1:19601`

但如果端口冲突，Polaris 会自动换端口，所以请以实际输出为准。

## Console 里有哪些页面

### 1. 首页

路径：

```text
/
```

适合第一次打开时先看一眼。

你会在这里看到：

- Polaris 是否在线
- 当前代理模式
- 最近请求
- 已保存请求数量
- Mock 数量
- MCP 是否开启

如果你不知道下一步做什么，首页通常会给你最快的入口。

### 2. 实时请求

路径：

```text
/traffic
```

这是最常用的一页。

适合做这些事情：

- 看当前抓到的请求
- 搜索某个接口
- 按方法、状态码、主机筛选
- 查看请求详情
- 复制 `curl`
- 把请求带入调试页
- 从请求创建 Mock

如果你是第一次用 Polaris，通常建议直接从这页开始。

### 3. 代理转发

路径：

```text
/proxy-forward
```

这页适合更细地管理“哪些流量该怎么走”。

适合做这些事情：

- 管理站点级转发规则
- 开启或关闭某条规则
- 改写目标地址、Host 或 Path
- 切换规则分组

如果你只是想抓包，可以先不用看这页。  
如果你要做转发联调，这页很重要。

### 4. 已保存请求

路径：

```text
/requests
```

这里放的是你手动保存过的请求。

适合做这些事情：

- 查看以前保存的请求
- 重新发送
- 编辑后再发
- 转成 Mock

如果你有一些常用接口想长期复用，这页会很有价值。

### 5. Mock

路径：

```text
/mock
```

这里用来管理 Mock 规则。

适合做这些事情：

- 新建 Mock
- 从真实请求生成 Mock
- 启用 / 停用 Mock
- 查看命中次数
- 切换 Mock 分组

V1 里主要支持的是“固定返回”的 Mock。

### 6. 调试

路径：

```text
/debug
```

这页像一个轻量请求调试器。

适合做这些事情：

- 手动填 URL 和参数发请求
- 修改已有请求后重发
- 看响应结果
- 保存请求
- 复制 `curl`

如果你想快速复现某个请求，通常会从这里处理。

### 7. 设置

路径：

```text
/settings
```

设置页主要放“技术信息和接入说明”。

你会在这里看到：

- 当前代理端口
- API 地址
- MCP 地址
- 证书状态
- HTTPS 抓包说明
- 手机接入说明
- MCP 接入说明

如果你遇到“为什么抓不到 HTTPS”或者“手机怎么接入”这类问题，优先看这页。

## 最常见的使用顺序

### 我只想抓浏览器请求

推荐顺序：

1. 启动 Polaris
2. 加载浏览器扩展
3. 在扩展里切到 `规则代理`
4. 把当前站点加入规则
5. 打开 `/traffic`

### 我只想把某个请求保存下来

推荐顺序：

1. 在 `/traffic` 找到目标请求
2. 打开详情
3. 点“保存请求”
4. 之后去 `/requests` 里复用

### 我只想做一个简单 Mock

推荐顺序：

1. 在 `/traffic` 找到真实请求
2. 点“创建 Mock”
3. 去 `/mock` 检查和启用

### 我只想让手机接入

推荐顺序：

1. 启动 Polaris
2. 打开 `/settings`
3. 查看局域网地址和代理端口
4. 手机访问 `http://polaris.local`
5. 按提示安装证书

## 几个容易卡住的地方

### 页面打开了，但一直没有请求

优先检查：

- Polaris 是否已经启动
- 浏览器扩展是否已经加载
- 当前是否真的启用了 `规则代理` 或 `全局代理`
- 当前站点是否已经加入规则

### 能打开页面，但 HTTPS 看不到内容

这通常和证书有关。

建议直接去：

- `/settings`

重点看：

- 证书是否已经安装
- 是否已经信任根证书
- HTTPS 是否已具备基础就绪条件

### 为什么请求很多，不知道先看哪个

建议先在 `/traffic` 里用这几个筛选：

- Host
- Method
- 关键词
- 状态码

通常很快就能把范围缩小。

## 哪些事不适合在 Console 做

Console 很适合看请求、调试请求、做 Mock、看设置。  
但下面这些事更适合交给别的入口：

- 快速切代理模式：更适合用浏览器扩展
- 把能力接给 AI 工具：更适合看 MCP 文档
- 修改 Polaris 本身：更适合看开发文档

# 浏览器扩展使用说明

扩展是 Polaris 的快捷控制面板，负责：

- 显示服务状态
- 切换代理模式
- 当前站点加入/移除规则
- 打开 Console 与设置页

## 安装前准备

```bash
polaris start
polaris extension-path
```

`polaris extension-path` 输出目录即扩展加载目录。

## 安装步骤（Chrome / Edge）

1. 打开扩展管理页
2. 打开开发者模式
3. 选择“加载已解压扩展程序”
4. 选择 `polaris extension-path` 输出目录

## 代理模式

- `直连`：不经过 Polaris
- `全局代理`：浏览器流量统一走 Polaris
- `规则代理`：仅命中规则的站点走 Polaris（推荐日常使用）
- `跟随系统`：跟随系统代理配置

## 当前站点规则行为

点击“仅代理当前站点”会新增站点规则；  
如果当前模式不是 `规则代理`，扩展会提示“切到规则代理后生效”，不会强制自动改模式。

## 连通性与端口发现

扩展会优先使用最近成功 API 端口，不通时扫描候选端口（默认从 `19601` 起连续扫描），因此在 Core 自动换端口后通常可自动恢复。
